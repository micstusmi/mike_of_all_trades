MIKE OF ALL TRADES — V9.2 INVOICE ROUNDING CORRECTION

Work Tracker retains the exact recorded session duration. Zoho previously
received labour quantity rounded to two decimal hours, causing a four-cent
difference: $150.46 in Work Tracker versus $150.50 in Zoho.

V9.2 sends six-decimal quantity and rate precision so Zoho reproduces the
authoritative Work Tracker amount to the cent. Existing GST and total safety
checks remain enabled. No database migration is required.
