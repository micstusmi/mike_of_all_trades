MIKE OF ALL TRADES — V8.38 IPHONE VIDEO SAVE
=============================================

Completed reels now show two clearly separated actions:

- Download to computer
- Save to iPhone Photos

The iPhone action fetches the MP4 and opens the native iOS share sheet with the
video attached. The user can then choose "Save Video" to place it in Photos.
While the file is being prepared, the button displays "Preparing video...".

If file sharing is unavailable, the website opens the video and explains that
the iPhone Share button followed by Save Video is the fallback route.
